# Third-party assets

Copied unmodified from the Terrain3D v1.0.2 demo (`demo/assets`), so the project does not depend on the demo folder.

- `textures/ground037_*`, `textures/rock023_*`: ambientCG Ground037 and Rock023, CC0 1.0 (see `textures/asset_licenses.txt`).
  Pre-packed for Terrain3D: `*_alb_ht.png` is albedo + height (alpha), `*_nrm_rgh.png` is normal + roughness (alpha).
- `models/RockA|B|C.glb`: rock meshes shipped with the Terrain3D demo. The demo repository is MIT licensed; the
  files carry no separate license notice, so confirm their terms before any redistribution.
- `materials/rock_triplanar.tres`: material written for this project, modelled on the demo's world-triplanar rock material.
