# Adaptive LOD in Godot: presentation package

- Adaptive_LOD_Godot.pptx: editable 8-slide deck (native charts and tables; speaker notes embedded)
- Adaptive_LOD_Godot.pdf: PDF export
- speaker_script.md: per-slide script
- checklist_missing_evidence.md: what to supply or run
- charts/: PNG charts and the LOD schematic (matplotlib, generated from results/m4_*.csv)
- images/: screenshots used (from cgg-falod/results/probe/smooth/)
- build/: generators (prep.py computes stats and charts, make_deck.js builds the deck), stats.json
